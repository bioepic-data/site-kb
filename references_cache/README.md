# Reviewed public reference text

These Markdown files were generated by `linkml-reference-validator` 0.3.0 from
the public NGEE Tropics Phase 2 proposal on 2026-10-15. Each contains the complete
PDF text extraction, not text assembled from our evidence quotations. The
validator keys the three page-anchored URLs separately; the underlying document
is the same. Page fragments support browser navigation, not page-scoped matching.

Do not hand-edit cached source text to make a quotation pass. Review a source
refresh explicitly with `just fetch-reference URL --no-cache`, inspect the diff,
then run `just validate-references`. Configuration trusts reviewed cache entries
so normal validation does not silently replace them with changed remote content.
New uncached sources can still be fetched and must be reviewed before committing.

The cache verifies quotation presence after the validator's formatting
normalization. It does not validate page numbers, source authority, claim support,
coordinate transformations, or geographic footprint equivalence. Source citations
without quotations do not undergo excerpt matching.
