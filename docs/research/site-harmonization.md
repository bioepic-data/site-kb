# Site harmonization

Started 2026-11-03. Design decisions agreed with the project lead:

- Unified sites, Mondo-style: one record per real-world site, with the source
  records that describe exactly that site kept as members (sub-records).
- Readable slug IDs for curated clusters. Uncurated singletons keep their record
  ID; member record IDs survive as redirects in the browser.
- Parts are separate sites, not members. A flux tower within a NEON site is its
  own site with `PART_OF`, so plots within sites within larger sites can nest.
  Containment is checked against bounding boxes.

## Seed: NEON (2026-11-03)

`db/curated/harmonization/neon.yaml` was generated by `just propose-site-links`
and reviewed:

- 81 clusters: each NEON record with the DEIMS record whose ID NEON's API lists
  (origin SOURCE). The NEON record comes first, so NEON coordinates, status, and
  site type win; DEIMS supplies the description, elevation, and boundary box.
- 47 `PART_OF` relations: AmeriFlux towers named "NEON … (CODE)" (45 `US-x**`
  and 2 `PR-x**`) within their NEON site (origin CURATED; the naming is a
  convention, not an explicit part-of assertion). 43 are geo-consistent; 4 are
  uncheckable because the site has no usable boundary.
- 22 `COLOCATED_WITH` pairs from the NEON field site export's `colocated_site`
  column (pipe-separated for OSBS and TOOL), each asserted once.

Result: 2,365 source records become 2,284 sites; 162 member records are kept as
`source_records`.

## Source problems found by geo checks

- JORN: the DEIMS boundary for "Jornada Experimental Range NEON" is identical to
  the boundary of "The Jones Center At Ichauway NEON" (Georgia, ~2,200 km away).
  `db/curated/overrides/deims_neon_geometry.yaml` removes it; the tower check is
  uncheckable.
- BLAN: the DEIMS point and boundary lie ~8 km from NEON's coordinates, and the box
  excludes both NEON's point and the US-xBL tower, so it likely covers one parcel.
  The override removes the box; the cluster carries a waiver.
- BLWA: the DEIMS point equals NEON TOMB (Lower Tombigbee) coordinates, ~80 km
  from NEON's BLWA point. The cluster carries a waiver; NEON coordinates are used.

These are worth reporting to DEIMS. Raw snapshots are unchanged.
